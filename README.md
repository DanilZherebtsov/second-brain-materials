# second-brain-materials

Учебные материалы к воркшопу **«Второй мозг»** (работа в Claude Cowork). Это вымышленные демо-данные — на них участники учатся собирать «второй мозг» под своё дело.

## Как скачать

Зелёная кнопка **«< > Code»** вверху → **Download ZIP** → распакуйте.

## Что внутри

Папки по доменам-примерам. Для каждого воркшопа используется один:

- **`coffee-shop-project-materials/`** — кофейный бизнес «Ладья»:
  - `изначальные-документы/` — рабочие файлы «до всякого ИИ» (бренд, договоры, меню, резюме, финансы, презентации), которые заносят в проект в начале воркшопа;
  - `фин-стандарты/` — корпоративный финстандарт для демо роли «Финансист»;
  - `Промпты_воркшопа.docx` — все команды воркшопа по порядку, для копирования.

- **`it-pm-project-materials/`** — студия внедрения ИИ «Evo-ai» (для проджект-менеджеров ИТ/ИИ-компаний):
  - `изначальные-документы/` — рабочие файлы проджект-менеджера «до всякого ИИ» (манифест и логотип бренда, договор на разработку с клиентом «Гермес», 20 резюме ML/LLM-инженеров, каталог решений, КП от вендоров инференса, бюджет проекта, презентации, фидбэк пилота);
  - `проектные-стандарты/` — корпоративный стандарт проектной экономики (ПС-01…ПС-04) для демо роли «Финансист»;
  - `Промпты_воркшопа.docx` — все команды воркшопа по порядку, для копирования.

В папке **`шпаргалка/`** — **`Шпаргалка_Cowork.docx`** (и английская `Шпаргалка_Cowork_en.docx`): общая памятка по работе в Cowork (приёмы, режимы, безопасность, план первой недели), одинаковая для всех доменов.

Дальше репозиторий пополняется материалами под другие домены (юрфирма, финкоманда и т. д.).
