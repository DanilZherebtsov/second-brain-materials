# second-brain-materials

Учебные материалы к воркшопу **«Второй мозг»** (работа в Claude Cowork). Это вымышленные демо-данные — на них участники учатся собирать «второй мозг» под своё дело.

## Как скачать

Зелёная кнопка **«< > Code»** вверху → **Download ZIP** → распакуйте.

## Что внутри

Папки по доменам-примерам. Для каждого воркшопа используется один:

- **`coffee-shop-project-materials/`** — кофейный бизнес «Ладья»:
  - `изначальные-документы/` — рабочие файлы «до всякого ИИ» (бренд, договоры, меню, резюме, финансы, презентации), которые заносят в проект в начале воркшопа;
  - `фин-стандарты/` — корпоративный финстандарт для демо роли «Финансист»;
  - `Промпты_воркшопа.docx` — все команды воркшопа по порядку, для копирования.

- **`it-pm-project-materials/`** — студия внедрения ИИ «Evo-ai» (для проджект-менеджеров ИТ/ИИ-компаний):
  - `изначальные-документы/` — рабочие файлы проджект-менеджера «до всякого ИИ» (манифест и логотип бренда, договор на разработку с клиентом «Гермес», 20 резюме ML/LLM-инженеров, каталог решений, КП от вендоров инференса, бюджет проекта, презентации, фидбэк пилота);
  - `проектные-стандарты/` — корпоративный стандарт проектной экономики (ПС-01…ПС-04) для демо роли «Финансист»;
  - `Промпты_воркшопа.docx` — все команды воркшопа по порядку, для копирования.

- **`dev-project-materials/`** — команда разработки студии «Evo-ai» (воркшоп для программистов, Claude Code в VSCode):
  - `изначальные-документы/` — рабочие файлы разработчика «до всякого ИИ» (исходники сервиса `hermes-assistant`, баг-репорты и логи пилота, постмортем инцидента, выгрузка командного чата, ТЗ, договор, фидбэк, КП вендоров, материалы студии);
  - `инженерные-стандарты/` — инженерные стандарты студии (ИС-01…ИС-04) для демо роли security-reviewer;
  - `Промпты_воркшопа.docx` — все команды воркшопа по порядку, для копирования.

- **`realty-project-materials/`** — бутиковый девелопер «Эпиграф» (для руководителей девелоперских компаний):
  - `изначальные-документы/` — рабочие файлы коммерческого директора «до всякого ИИ» (бренд, концепция и ТЭП клубного дома «Гравюра», финмодель, договор генподряда, КП на фасад, отзывы покупателей и брокеров, презентации, заметки планёрки, каталог резиденций, 20 тизеров участков);
  - `фин-стандарты/` — корпоративный финстандарт девелопера (ФС-01…ФС-04) для демо роли «Финансист»;
  - `Промпты_воркшопа.docx` — все команды воркшопа по порядку, для копирования.

В папке **`шпаргалка/`** — **`Шпаргалка_Cowork.docx`** (и английская `Шпаргалка_Cowork_en.docx`): общая памятка по работе в Cowork (приёмы, режимы, безопасность, план первой недели), одинаковая для всех доменов. Для воркшопа программистов — **`Шпаргалка_Claude_Code.docx`** (второй мозг в Claude Code и VSCode).

Дальше репозиторий пополняется материалами под другие домены (юрфирма, финкоманда и т. д.).
