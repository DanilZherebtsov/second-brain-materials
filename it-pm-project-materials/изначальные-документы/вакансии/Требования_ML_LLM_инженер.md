# Вакансия: ML/LLM-инженер, Evo-ai (проект «Гермес»)

*Внутренний документ для рекрутинга. Версия 1.0. Июнь 2026.*
*Открыта под флагманский проект — ИИ-ассистент поддержки для ООО «Гермес-Логистика» (бренд «Гермес»). Запуск в прод — до 01.10.2026.*

---

## Что мы ищем

ML/LLM-инженер в команду проекта «Гермес» — внедрение ИИ-ассистента поддержки (LLM+RAG над базой знаний «Гермеса»: регламенты, тарифы, статусы грузов, FAQ; интеграция с их helpdesk). Это ядро ассистента: RAG, промптинг, оценка качества. Работаем удалённо, ядро команды — Москва (МСК), спринт-ритм по 2 недели. Студия Evo-ai внедряет ИИ, который работает в проде, а не на демо; нам нужен инженер, который доводит решение до прода и меряет результат. Подробнее про компанию — в `бренд/Манифест_Evo-ai.md`.

## Обязательные требования

- **Опыт ML/LLM — от 2 лет.** Для джунов/стажёров — исключение при сильном пет-портфолио и горящих глазах.
- **Python (уверенно).**
- **Практический опыт с LLM API** (промптинг, function calling) **И RAG** (эмбеддинги, vector DB).
- **Минимум один доведённый до прода проект на LLM/ML в портфолио.**
- **Готовность к спринт-ритму** (2-недельные спринты) **и дежурствам on-call по очереди.**

## Сильные плюсы (повышают приоритет)

- **RAG в проде** (не только пет-проекты).
- **Один из langchain / llamaindex / собственный пайплайн.**
- **Оценка качества** (eval, метрики галлюцинаций/точности).
- **Английский** — чтение доков и общение (минимум разговорный).
- **Вклад в open-source / Kaggle / публикации.**
- **Опыт интеграций** (helpdesk/CRM/API).
- **Таймзона с overlap ≥ 4 часов с командой (МСК).**

## Дополнительные плюсы (приятно иметь)

- MLOps (Docker, CI/CD, мониторинг моделей).
- Опыт в highload / логистике / e-commerce.
- Профильное образование (CS/ML) — но не обязательно.

## Что НЕ важно

- Формальный диплом (любой).
- Конкретный фреймворк — научим.
- Опыт именно в нашем стеке.

## Что мы предлагаем

- Вилка **200–350 тыс. ₽/мес** по грейду.
- Удалёнка.
- Оплата обучения/конференций.
- IT-аккредитация компании (льготы).

1. **Скрининг резюме** (этот этап). На тех. интервью берём топ-5 по соответствию.

3. **Лайв-кодинг / тестовое задание.**
4. **Оффер.**
