# Промпты воркшопа «Второй мозг» (кофейный пример)

Здесь по порядку собраны команды, которые мы вводим в Claude Cowork на воркшопе. Номера совпадают с номерами в сценарии: ведущий называет номер промпта — вы копируете его отсюда. Места вроде «Лесная, 7» или «Парковая, 22» — из учебного примера; в своём проекте подставляйте своё.

*Файл собран из сценария воркшопа автоматически — он всегда ему соответствует.*

---

### 1. Блок 1 · Первое сообщение конструктору (кто я и чем занимаюсь)
```
Я занимаюсь кофейным бизнесом «Ладья» (основатель — Денис Лобанов). Строю себе помощника для управления делом: решения, контрагенты, найм, финансы, маркетинг, договоры, риски. Первой задачей возьмём открытие второй точки кофейни. [Добавьте сюда всё, чем занимаетесь.] Собери под это структуру проекта.
```

### 2. Блок 3 · Обработать занесённые документы
```
Первой задачей возьмём открытие второй точки кофейни «Ладья» в Екатеринбурге (выбор из трёх помещений). Я загрузил мои рабочие папки с материалами вразнобой (бренд, договор аренды, резюме бариста, меню, КП поставщиков, финансы, презентации, отзывы). Разбери все эти документы и наведи порядок.
```

### 3. Демо 1 · Анализ отзывов
```
Открой отзывы клиентов первой точки — Ольга собрала их в один файл.

Найди этот файл, сделай аналитический отчёт по отзывам:

1. Раздели все жалобы и пожелания на категории (например: цены, скорость, шум, мебель, освещение, ассортимент).
2. Для каждой категории — сколько раз встречается, конкретные цитаты (1-2), и что это значит для нас при открытии второй точки.
3. Отдельно выдели, что пишут позитивного — это наши сильные стороны, надо сохранить.

Сохрани результат как Анализ отзывов

Перед началом задай мне 1-2 уточняющих вопроса, если что-то непонятно.
```

### 4. Демо 1 · Итерация: раздел про локацию
```

```

### 5. Демо 1 · Excel: сравнение поставщиков
```
Теперь открой КП от поставщиков кофе (Excel с ценами и условиями).

Там цены и условия в разном формате (рубли/доллары, разные единицы, разные форматы доставки). Приведи к единому формату:
— все цены в рубли за килограмм (если в долларах — посчитай по курсу 92 ₽/$);
— столбец «Минимальный заказ, кг» (только число);
— столбец «Доставка включена в цену»: да/нет;
— столбец «Постоплата возможна»: да/нет/частично.

Сохрани новый файл как Сравнение_поставщиков_2026-06.xlsx. Исходный файл не трогай.

В конце — короткий вывод текстом: какой поставщик выгоднее всего по совокупности параметров.
```

### 6. Демо 1 · Запомнить решение по поставщику
```
Запомни это: по результатам сравнения поставщиков выбираем Skuratov — цена близка к минимуму, доставка не добавляет процентов сверху, постоплата помогает на старте, а низкая минималка даёт возможность тестировать без риска. Coffee Project оставляем как запасного на случай перебоев.

Сохрани как Разбор_договора_Лесная.md.

ВАЖНО: указывай для каждого пункта номер пункта в исходном договоре, чтобы я мог проверить.
```

### 13. Блок 8 · Массовая обработка 20 резюме
```
В проекте есть папка с 20 PDF-откликами на вакансию баристы для второй точки и файл с требованиями к кандидату.

Сделай:

1. Прочитай все 20 резюме по очереди. Для каждого извлеки в нормализованную форму: ФИО, возраст, опыт в общепите (лет), последнее место работы, наличие сертификата SCA или аналога, локация (район Екатеринбурга), знание английского (базовый / разговорный / нет), готовность работать по сменному графику.

2. Сохрани таблицу как output/черновики/Резюме_бариста_сводка.xlsx. В таблице — 20 строк, по одной на кандидата.

3. Поставь каждому балл от 1 до 10 по соответствию требованиям из файла вакансии. Балл — отдельным столбцом, обоснование в одной строке — соседним.

4. Отсортируй по баллу. Топ-5 — выделить заливкой.

5. В конце — короткий комментарий текстом: на кого из топ-5 ставить приоритетное собеседование и почему.
```
