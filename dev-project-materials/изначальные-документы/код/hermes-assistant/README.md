# hermes-assistant

ИИ-ассистент оператора поддержки ООО «Гермес-Логистика». Оператор вставляет вопрос клиента — ассистент предлагает готовый ответ со ссылкой на пункт регламента, считает стоимость перевозки по тарифам и показывает статус груза по номеру `ГЛ-XXXXXX`.

Проект Evo-ai «Гермес», версия 0.4.2.

## Как это работает

- **Поиск по базе знаний** — Elasticsearch, индекс `hermes-kb`. В индекс загружены регламенты из `kb/regulations/` (R-01…R-08), поиск BM25 с русской морфологией.
- **Генерация ответа** — LLM МодельАПИ. Таймаут запроса к LLM — 3 с, 2 ретрая с экспоненциальной паузой; если МодельАПИ недоступен или отвечает 429, запрос автоматически уходит в fallback на TokenFlow.
- **Эскалация на старшего смены реализована (`/api/escalations`)**: если ассистент не нашёл ответ в регламентах или уверенность ниже 0,5, обращение передаётся старшему смены в helpdesk, а оператор видит статус передачи в виджете.
- **Тарифы** — расчёт по R-03: (базовая ставка + ставка за кг × вес) × коэффициент зоны.
- **Статус груза** — из helpdesk заказчика по номеру `ГЛ-XXXXXX`.

## API

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/health` | статус и версия сервиса |
| POST | `/api/chat` | подсказка ответа: `{"message": "...", "session_id": "...", "channel": "chat"}` |
| GET | `/api/regulations/{doc_id}` | текст регламента, например `/api/regulations/R-04` |
| POST | `/api/escalations` | передать обращение старшему смены |

Пример ответа `POST /api/chat`:

```json
{
  "answer": "Здравствуйте! Претензию нужно подать в течение 20 календарных дней с даты выдачи груза; ...",
  "citations": [{"doc_id": "R-04", "title": "Повреждение, недостача и претензии", "clause": "4.4"}],
  "confidence": 0.57,
  "latency_ms": 3
}
```

## Запуск

```bash
docker compose up
```

Поднимутся API на http://localhost:8000 и Elasticsearch с индексом `hermes-kb`. Виджет оператора — http://localhost:8000/.

## Тесты

```bash
pip install -r requirements.txt
pytest -q
```

Качество поиска по регламентам (recall@k на наборе вопросов из `eval/questions.jsonl`):

```bash
python eval/run_eval.py --chunking fixed
```

## Структура

```
app/
  main.py          FastAPI: маршруты API, статика виджета
  pipeline.py      сценарий ответа: тариф → статус груза → поиск по регламентам
  retrieval.py     поиск по базе знаний
  llm.py           клиент МодельАПИ
  tariffs.py       тарифы и расчёт стоимости
  helpdesk.py      клиент helpdesk заказчика (статус груза)
  kb_loader.py     загрузка регламентов
  metrics.py       метрики запросов
  config.py        настройки
  schemas.py       схемы запросов и ответов
  static/          виджет оператора
kb/regulations/    регламенты «Гермес-Логистики» (R-01…R-08)
eval/              вопросы с эталоном и замер recall@k
tests/             тесты pytest
```
